# V2候选来源改造：待ECS接入

2026-09-15用户确认先修改候选生成。目标是在终审之前召回具有上涨机会的股票；公司质量不等于股价上涨潜力。此目录是可执行候选召回模块及单元测试，尚未接入生产ECS；不能据此宣称主任务已恢复。

## 三条候选来源

1. 先行股：最近5个交易日率先放量突破此前20日高点，或在指数下跌日相对抗跌且出现量价确认。独立资金驱动可以进入此来源，无需编造重大利好。
2. 细分题材联动：采用有来源和生效日期的多标签题材映射；至少3只股票确认，且占有效成员至少50%。单股大涨不算板块联动。题材可跨行业，行业字段仍保留；不硬编码华正新材、风华高科、沃尔德或任何行业白名单。
3. 确认跟随：同题材已有较早突破者，本股稍后突破且近期量价确认；既有扩张护栏明确未触发才进入跟随来源。护栏未知不视作未触发；护栏触发仍可进入先行/联动观察来源，不作为正式V2否决。

实现首版参数：突破成交量为此前10日均量的1.2倍；当前确认要求3日收益与相对基准收益均为正、当日量比>=1.2；突破观察窗口5个交易日。参数是待真实输入验收的工程初值，不是经回测证明的最优阈值。保持既有KDJ、动量评分和最终七项权重不变。只有来源内比较和候选召回顺序改变。

各池分别对三条来源轮询召回、按代码去重，容量仍为池内最多30、池外最多10。余位按上游原quant_rank补齐，显式标记legacy_quant_fallback；不足不凑数。来源数量不是最终分，不将同一量价指标重复相加，也不承诺涨幅。

## 接口与数据要求

`build_candidates(rows, benchmark, trade_date, universe_complete=True)`仅接受完成现行V2市场/股票池范围检查后的完整扫描宇宙。不得把既有30+10截断包当作完整输入。每行保留原量化字段及KDJ，另提供：

- ts_code、origin=official_pool/external_pool、v2_universe_eligible、原quant_rank。
- bars：至少26个连续基准交易日的date（ISO日期）、同一复权口径close/high及volume；benchmark为相同日历的date/close。停牌、缺数、无效数值不能填默认值；记录被排除原因。存在行情缺失时本版保守禁止题材联动判定，避免缩小分母后虚增广度。
- themes：theme_id、effective_from、可选effective_to、published_on、source_url、verified。仅使用截至交易日已公开且有效的映射。必须由真实资料核验生成，不能因股价表现反向捏造业务关联。只保存事实摘要和链接，不保存PDF/网页快照。
- timing_guard_triggered：由现有V2护栏计算，仅明确false才允许跟随来源。

输出pools中保留原候选字段（不携带bars），新增candidate_source说明版本、日期、来源、题材、窗口内突破日期和量价依据。顶层保存theme_stats、rejected、route_counts和coverage_gap。adapter须将两池写回既有official_review_candidates/external_review_candidates，并绑定输入日期/哈希与candidate_generation_version。主题广度代表完整合格扫描宇宙，不宣称全市场全概念覆盖。

## 接入及验收顺序

1. 在真实ECS读取stock_key10_v2_daily.py及scoring.py当前源码和配置，定位30+10截断前的完整候选表，备份当前文件。不能覆盖未知版本源码。
2. 在截断前提供完整行情、基准日历及带日期题材映射；调用本模块。沿用原市场资格、池归属、量化评分、KDJ算法与发布链路。先写临时输出，不覆盖历史/latest。
3. 使用真实全量输入验收：新增召回能包含旧40只之外的股票；来源可解释；去重及30+10上限；所有原评分/KDJ字段逐代码不变；日期、复权、未来数据守卫通过；池外不自动入池。
4. 验证正式JSON与文字报告消费者接受新增诊断字段；模拟接收、终审检查点恢复和文字双回执。不重启PNG。
5. 只有上述检查通过并真实接入生产调用链，才标记deployed；首个自然交易日完成文字交付后才称端到端通过。当前自动化计划和启用状态未改。

本目录测试采用合成行情，只证明选择器边界行为，不证明收益能力或生产数据兼容性。当前缺少ECS执行通道、生产源码和完整扫描宇宙，真实集成及全链路验收尚未完成。

## 2026-09-16 修正后的接入约束

- 题材广度的分母先按交易日有效、已核验的题材成员建立，再应用行情有效性；无关股票行情缺失不会阻断其他题材，题材成员行情缺失不会从分母中删除，并使该题材联动保守降级。
- 先行和跟随关系按事件发生日重新核验题材映射；交易日当天新增或未来公开的标签不能倒推早期事件。`breakout_date_5session_window` 只表示最近五个交易日观察窗内的首个突破，不表示整轮行情启动日。
- 基准与个股 bars 必须有至少26个与交易日历完全相同的日期、统一且显式的 `price_basis`，并使用正的收盘价、最高价和成交量；缺失、未来日期、复权/成交量口径不一致均拒绝该行，不填默认值。
- `candidate_generation_version` 已提升为 `v2_candidate_sources_20260916`。诊断字段只描述来源、证据日期、题材覆盖和量价依据，`final_score_effect=0`、`entry_signal=false`，不进入七项评分、排序或准入。
