# 股票项目：概念题材标签规则

版本：1.2  
更新日期：2026-09-19  
适用范围：股票 Stock 项目的股票池题材整理、亿信结果归并、批次复核及后续题材库维护。

## 1. 核心目标

用简短、常用、粒度一致的主标签，识别股票之间的板块与资金联动。每只股票只保留一个核心交易题材，具体业务差异放入说明。

标签描述当前研究采用的交易归类，不自动代表公司主营收入占比、业务成熟度、上涨原因已经证实，也不代表买入建议。

## 2. 主标签选择

1. 优先选择有依据、最能解释当前交易受益逻辑的题材，不机械选择收入最大或历史最主要的业务。
2. 当前催化指向新业务时，可以用新业务题材作为主标签；在说明中保留传统主业、新业务阶段和收入贡献边界。
3. 没有近期催化，仍可依据主营、产品应用与市场概念归属确定基础标签。不能因为亿信未返回资料就直接将补查工作交给用户。
4. 一股一个主标签，不堆砌多个题材，不用“甲醇/尿素涨价”“煤电保供+绿电转型”等拼接标签。
5. 新股票先匹配已有标准名称；有实质区别且现有名称不适合时才新增标签。
6. 不因股价上涨就倒推故事，不把用户交易观察（如“庄股”）写成已证实事实或题材。

## 3. 命名与分类粒度

采用常用中文名称；MLCC、PCB、CPO、CRO等已认可的常用简称可以保留。避免ASIC等用户认为过于抽象的主标签，保留在说明中即可。

| 业务或旧标签 | 统一主标签 | 说明保留的信息 |
|---|---|---|
| 半导体清洗、刻蚀、沉积、检测、量测设备 | 半导体设备 | 具体工艺和设备环节 |
| 半导体硅片、靶材、光刻胶、CMP抛光材料、电子特气 | 半导体材料 | 产品、应用、量产与验证阶段 |
| AI办公、AI营销、AI短剧 | AI应用 | 具体场景、收入占比 |
| 国产GPU、国产AI计算芯片、AI定制芯片 | 国产算力 | 通用GPU、AI芯片、定制设计/IP等角色 |
| 存储主控、接口芯片、模组、分销、存储封测 | 存储芯片 | 具体产业链角色；不得冒充存储原厂 |
| 创新药授权出海、创新药商业化 | 创新药 | 授权收入与药品销售分开 |
| 仿制药研发及商业化 | 仿制药 | 不能因药物赛道热门而归为创新药 |
| 诊断与医疗设备 | 医疗器械 | 产品及应用领域 |
| AI服务器PCB | PCB | 板型及终端场景 |
| 高速覆铜板、覆铜板涨价 | 覆铜板 | 普通/高端产品、涨价催化 |
| 高端电子布、电子布涨价 | 电子布 | 普通/低介电等产品差异 |
| 高速覆铜板树脂 | 电子树脂 | 上游角色 |
| 高频高速铜箔 | 铜箔 | 产品代际与应用 |
| PCB油墨、PCB焊接材料 | PCB材料 | 油墨、锡膏等角色 |
| 光学膜、功能性BOPP薄膜 | 功能薄膜 | 具体膜种及用途 |
| 锂矿、锂盐 | 稀有 | 具体金属为锂；采矿、冶炼或加工角色 |
| 白银涨价、甲醇涨价、油运景气 | 贵金属、甲醇、油运（分别对应） | 白银为具体金属；价格及景气变化作为催化 |

医药保留创新药、仿制药、医疗器械、脑机接口、CRO等常用类别，不能全部压成“医药”。储能逆变器可统一为储能，产品角色写入说明。

## 4. 保留必要区别

分类粒度一致不等于把所有相关股票无限合并。以下已认可类别保留：

- PCB、IC载板、PCB设备、PCB材料、覆铜板、电子布、电子树脂、铜箔、复合铜箔、电池铝箔。
- MLCC、AI电感、金刚石散热。
- 光纤光缆、光芯片、光模块、CPO、光交换、高速连接器、交换机、交换芯片。
- 算力租赁、国产算力、数据中心供电、液冷。
- 晶圆代工、先进封装、功率半导体、碳化硅、玻璃基板。
- 贵金属（资源/冶炼）与黄金珠宝（零售）；有色、稀有按本项目金属三类规则；油运与船舶配套。

不能仅因名称含“材料”，就将光通信材料、PCB材料、金刚石材料全部并入半导体材料。磷化铟、铌酸锂等已认可的独立交易题材暂保留。

机器人与人形机器人、工业机器人等已使用标签不擅自全量合并；有明确调整需求时统一复核，而不是逐批随意更名。


## 4.1 本轮统一分类与后续强制复用（2026-09-19）

当前标准词表及229只映射以同名总表v2.0为准；本节最新修订优先于旧别名。后续批次只输出标准名称，不能又采用括号、斜杠或产品代际造新标签。一个主标签＋独立业务兑现字段不变。

### 金属三类

这是项目自定义、互斥输出的交易分类；不表示贵金属、稀有金属在学术上不属于有色金属。

| 标准主标签 | 项目归并范围 | 当前映射例 |
|---|---|---|
| 贵金属 | 金、银、铂、钯等资源开采、冶炼价格逻辑 | 湖南白银、盛达资源、山金国际 |
| 有色 | 铜、铝、铅、锌、锡、镍等常用工业金属价格逻辑 | 洛阳钼业、紫金矿业、锡业股份、豫光金铅 |
| 稀有 | 锂、钴、钨、钼、锗、镓、铟、锆、钽、铌、稀土等；按本项目固定映射 | 三祥新材、天华新能、江特电机、中钨高新、云南锗业、融捷股份、华友钴业、天齐锂业 |

具体金属必须保留在说明中，防止把同一大类误当作同一价格周期。多金属公司沿用已选核心逻辑：紫金矿业沿铜线归有色，华友钴业沿钴线归稀有。金属未知或主线冲突时保留待核验，不用含糊名称任意切换。

本归并针对金属资源/冶炼价格题材，不吞并已确认的功能材料、零部件与终端应用题材。黄金珠宝、铜箔、复合铜箔、电池铝箔、半导体材料、磷化铟、铌酸锂保留；东方钽业保留半导体材料，安泰科技保留可控核聚变，江钨装备保留磁选装备。后续只有核心交易逻辑改变才调整，不看名字强制归金属。

|---|---|---|

机器人、人形机器人、工业机器人继续保留现有区别；高速铜缆与高速连接器保留区别。CPO统一不意味着把光芯片、光模块、光纤光缆、光交换全部并入CPO。

后续处理顺序：先识别当前交易逻辑→匹配标准词表→映射别名→记录兑现与来源状态→检查一股一标签、代码唯一及数量。无现成分类且确有新逻辑时提出新增类别，由用户确认后同步规则与总表；证据不足标待分类/待核验，不擅自新增同义词。不得以总表标签为事实核验或短线推荐的替代品。

## 6. 主标签、业务兑现、说明、催化分别记录

主标签只保留一个常用题材名。说明保留具体产品、产业链角色、客户、技术代际、收入贡献及业务阶段；催化记录价格、订单、重组、出海授权等事件与日期。

“重组不放入主标签”不等于重组不影响主标签选择：控制权或新业务事件若形成有依据的交易主线，可以改变所选题材，事件本身仍记录在催化中。

必须区分：研发、送样、认证、小批量、量产、实际收入；框架协议、采购计划与已执行订单；药品申请受理与获批；业务关联与当前股价驱动。

### 6.1 业务兑现标记

采用“核心题材＋业务兑现标记”。主标签仍只有一个标准题材名；兑现标记单独存储，展示时可写为“PCB设备〔收购推进，收入归属待核验〕”或“商业航天〔低收入贡献〕”，不拆出新的题材类别。

| 标记 | 使用边界 |
|---|---|
| 已有收入 | 有依据确认相关业务已产生收入；有披露时保留金额、占比与统计期间，不等同于已盈利 |
| 低收入贡献 | 已有相关收入但贡献较低；保留实际占比及期间，不擅设统一数值阈值 |
| 尚无收入 | 有明确依据确认尚未产生相关收入；不能从未披露推断为零 |
| 未披露收入 | 无可定位的单独收入披露；保持未知，不当作尚无收入 |
| 未并表 | 标明相关标的或资产未进入上市公司合并报表；不代表标的自身没有收入 |
| 收购推进／规划／研发／送样／小批量／量产 | 描述实际进展，可与收入标记并列；各阶段不自动等于收入或利润兑现 |
| 待核验 | 证据不足、来源不清或收入归属存在歧义时明确标注 |

记录相关业务的阶段、收入状态、金额或占比（如已披露）、统计期间、合并报表归属、来源与核验状态。用户确认交易归类与公司事实核验分别记录。标的公司收入不得直接算作上市公司收入。

### 6.2 同题材优先级

1. 在同一题材、相近量价结构和入场条件下，相关业务兑现程度与确定性作为优先级加分项；仅有规划、收购预期、尚无收入或低收入贡献的标的适度降权，不直接剔除。未披露收入或待核验应标为信息不确定，不能按已确认零收入处理。
2. 业绩兑现、订单驱动的市场阶段，提高真实相关收入和订单转收入确定性的权重；事件驱动、题材启动阶段，允许预期变化大的未兑现标的获得更高排序。
3. 综合预期差、催化强度、量价表现、资金关注、已累计涨幅和入场位置调整。市场表现已确认的领涨地位可使排序上调，但不能替代风险控制。
4. 收入贡献高、确定性强不直接推出最大涨幅；已被充分定价的优势可能缺乏收益空间。公司质量与交易质量分别判断。
5. 不由个别股票跑输直接推定“没有题材收入导致跑输”，须保留收购不确定性、题材关联强度、资金与起涨位置等其他解释。
6. 本规则为条件性排序原则，尚未确定固定扣分值或自动化权重，不据此声称已完成生产模型部署。

## 7. 来源与缺项处理

1. 亿信输出可作为研究输入，不要求先复刻同花顺完整概念库。市场标签、公司事实、研报判断分别保留。
2. 缺项由助手主动搜索企业官网、公告、投资者关系材料、主营产品和可访问的市场概念归属。仍无证据时如实标待核验，不编造。
3. 每项尽量保留来源主体、标题、日期、链接或可定位引用。只有“某券商研报”“公司公开资料”或日期，不算充分可追溯来源。
4. 同一原始材料的转载不算独立交叉证据；社区文章不自动等于公司或研报认证；来源截断须标记缺失。
5. 用户确认标签与来源独立核验分开。用户确认不代表所有财务数字、客户、订单和量产进度均已证实。
6. 原始文本错误可在确认后修正；本轮三处“先进接入”已由用户确认为“先进封装”，修正文案不改变标签。

## 8. 批次工作流程

1. 按股票代码核对名单、名称、重复与遗漏，临时XD等前缀不改变股票身份。
2. 读取当前标准词表，归并同义名称，主动补查缺项。
3. 输出“股票代码、股票名称、核心题材、业务兑现标记、简要说明”，重点指出真正需要用户判断的主线冲突。
4. 用户复核后保存当前标签、业务兑现标记、说明、来源和确认状态。后续变更同步修订已整理批次，避免新旧口径混用。
5. 清单完整、标签已选、用户确认、来源核验、生产接入是不同状态，不能混称完成。

## 9. 维护与模型使用

标签允许跨日复用，行情、题材热度和启动顺序每日更新。新证据或市场主线改变时修订标签，不把阶段性催化写成永久业务属性。

保留观察时间、核验时间及来源日期；未知历史生效日保持空值，不用采集日期倒填，不以今日标签倒推历史先行/跟随信号。

缺标签不自动剔除股票；部分题材库只能统计已覆盖成员。同标签只表示可研究联动，不代表一定同步上涨，更不替代量价、资金、催化及风险评估。
